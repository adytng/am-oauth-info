AgentMoney

AgentMoney 是一套個人自用的家庭記帳與資產彙整工具，只由擁有者本人在自己的設備上執行，不對外提供服務，也不開放註冊。

AgentMoney is a personal household bookkeeping tool. It is run only by its owner on the owner's own equipment. It is not offered to the public and has no sign-up.

它會用到的 Google 權限 / Google permissions it uses

  • 讀取擁有者自己信箱裡的帳單與交易通知信，並寄出每日彙報給擁有者本人。
    Reads statement and transaction notice mails in the owner's own mailbox, and sends a daily report to the owner.
  • 讀取擁有者自己雲端硬碟裡的對帳單檔案。
    Reads statement files in the owner's own Drive.
  • 讀取擁有者自己的試算表中的匯率與行情。
    Reads exchange rates and prices from the owner's own spreadsheet.
